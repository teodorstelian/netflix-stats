# Netflix Stats

## Description
Netflix Stats is a project designed to analyze and visualize your Netflix viewing activity. It takes your Netflix `ViewingActivity.csv` and provides insights into your viewing habits with the help of visualizations and statistics.

## Features
- Upload your Netflix viewing history.
- View detailed statistics about your Netflix usage.
- Visualize data using interactive charts and graphs.
- Filter and categorize activities by profiles.

## Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/netflix-stats.git
   ```
2. **Navigate to the project directory**:
   ```bash
   cd netflix-stats
   ```
3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
1. Run the application:
   ```bash
   python main.py
   ```
2. Open your web browser and navigate to `http://localhost:5000`.
3. Upload your Netflix `ViewingActivity.csv` file.
4. Explore your Netflix habits through charts and statistics.

## Technologies Used
- **Programming Language**: Python 3.9.13
- **Frameworks**: Flask
- **Libraries**:
  - Pandas (for data manipulation)
  - Plotly (for interactive visualizations)
  - Jinja2 (for HTML templating)
- **Frontend**:
  - HTML
  - CSS

## File Details
- `main.py`: Contains the main application logic.
- `utils.py`: Helper functions for data processing and analysis.
- `uploads/`: Directory for storing uploaded files.
- `templates/`: Contains HTML templates for the application interface.
